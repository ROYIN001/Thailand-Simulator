# รัฐนาวา (Thailand Simulator)

เกมจำลองประเทศไทยแบบ «หนึ่งประเทศ หลายที่นั่ง» ผู้เล่นนั่งเก้าอี้จริงทีละตัว ทั้งฝั่งรัฐและเอกชน แล้วตัดสินใจด้วยข้อมูลจริง ทุกตัวเลขบนจอบอกได้ว่ามาจากแหล่งใด เป็นค่าคำนวณ หรือเป็นค่าของเกม

เป้าหมายคือเล่นแล้วเข้าใจว่าแต่ละภาคส่วนของประเทศทำงานอย่างไร และสนุกไปด้วย

## สถานะ (22 พ.ย. 2569)

- ออกแบบแล้ว ยังไม่มีโค้ด
- หลักไมล์แรก: ที่นั่งกรรมการบริหารกองทุนน้ำมันเชื้อเพลิง (กบน.) ที่นั่งเดียว ฉากวิกฤตกองทุนน้ำมัน 8–12 ตา ตาละหนึ่งสัปดาห์ เป็นเว็บ static เล่นได้ทั้งมือถือและ PC
- หน้าตาที่ใช้ต่อ: จอโต๊ะบน PC ในผืนออกแบบ หน้า "สร้างใหม่ตามฉบับแรก" (https://claude.ai/artifact/JkijqK1VtVJsXP8kLm4ALs)
