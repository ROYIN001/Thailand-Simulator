# ไฟล์ข้อมูลกลาง

แหล่งความจริงเดียวของค่าจริงทุกค่าในเกม (kickoff หัวข้อ 4 ข้อ 3) · โค้ดและหน้าจออ้างค่าด้วย `id` เท่านั้น · รูปแบบนี้ใช้ชั่วคราว เมื่อตั้งโค้ดในข้อ 5 schema ของ zod จะเป็นตัวกำหนดแทน และต้องตรงกับรายการข้างล่าง

## ระเบียนหนึ่งค่า

| ฟิลด์ | ความหมาย |
|---|---|
| `id` | ชื่อคงที่ ตัวพิมพ์เล็ก คั่นด้วยจุด เช่น `fund.position.total.2026-03-22` |
| `label` | ชื่อภาษาไทย |
| `value` | ตัวเลขตามแหล่ง ไม่ปัด · `null` ถ้าหาไม่ได้ หรือถ้าข้อเท็จจริงเป็นข้อความ (เช่น ตัวบทมาตรา) ซึ่งอยู่ใน `evidence` |
| `unit` | หน่วยตามแหล่ง เช่น `ล้านบาท` `บาท/ลิตร` `ล้านลิตร/วัน` |
| `asOf` | วันที่ของค่า (ค.ศ. YYYY-MM-DD) · ค่าที่เป็นช่วงเวลามี `period` เพิ่ม เช่น `2026-03` และ `asOf` เป็นวันที่ของเอกสาร |
| `source` | `{ url, publisher, title, kind }` · kind = `primary` (หน่วยงานเจ้าของข้อมูล) หรือ `secondary` (ข่าว) |
| `evidence` | ข้อความจากแหล่ง คัดตรงตัว ไม่เกิน 300 ตัวอักษร · ข้อความจาก PDF มาจากชั้นข้อความของไฟล์ สระและวรรณยุกต์ไทยอาจเพี้ยน ตัวเลขไม่เพี้ยน |
| `status` | `verified` ผู้ตรวจเปิดแหล่งต้นทางแล้วตรง · `secondary-only` มีแต่ข่าว · `conflict` แหล่งขัดกัน · `computed` คำนวณจากค่าอื่น (ระบุสูตรใน notes) · `missing` หาไม่ได้ |
| `checkedBy` | agent หรือคนที่ตรวจ และวันที่ตรวจ |
| `notes` | ข้อสังเกต เช่น วิธีคำนวณ ความต่างของนิยาม |

เกมใช้ได้เฉพาะค่า `verified` และ `computed` ที่มาจากค่า `verified` · ค่าอื่นแสดงเป็น "ยังไม่มีข้อมูล" (CLAUDE.md หัวข้อข้อมูลและตัวเลข)

ปี: ไฟล์ข้อมูลใช้ ค.ศ. · หน้าจอแสดง พ.ศ. (2569 = 2026)

## ชุด `oil-fund-2569/`

ข้อมูลของฉากกองทุนน้ำมัน ช่วง ก.พ.–มิ.ย. 2569 และค่าเดือน พ.ย. 2569 ที่ไฟล์แบบใช้ · หนึ่งไฟล์ต่อหนึ่งหัวข้อ แต่ละไฟล์เป็น array ของระเบียน

| ไฟล์ | เนื้อหา |
|---|---|
| `fund-position.json` | ฐานะกองทุนรายสัปดาห์ แยกบัญชีน้ำมัน/LPG · เงินกู้ · หนี้สิน |
| `rates.json` | อัตราเงินส่งเข้า/ชดเชยตามประกาศ กบน. · ค่าบวก = ส่งเข้ากองทุน ค่าลบ = ชดเชย |
| `prices.json` | โครงสร้างราคา สนพ./สกนช. (ขายปลีก ราคา ณ โรงกลั่น ภาษี) · ราคาตลาดโลกรายสัปดาห์ |
| `consumption.json` | ปริมาณจำหน่ายรายเดือนจาก ธพ. และ สนพ. |
| `law.json` | พ.ร.บ.กองทุนน้ำมันเชื้อเพลิง 2562 · กรอบวงเงินกู้ · แผนรองรับวิกฤต |
| `timeline.json` | ลำดับเหตุการณ์และมติ |
| `cpi.json` | ดัชนีราคาผู้บริโภคจาก สนค. |
| `verify-nov.json` | ตรวจตัวเลขเดือน พ.ย. 2569 ที่ `design/rebuild-desk-pc.dc.html` ใช้ |

ที่มา: ค้นคว้าและตรวจ 22 พ.ย. 2569 · ทุกหัวข้อมีผู้ค้นกับผู้ตรวจเป็นคนละ agent · ผู้ตรวจเปิดแหล่งต้นทางเอง · `verified` คือผู้ตรวจยืนยันกับเอกสารของหน่วยงานเจ้าของข้อมูล · `secondary-only` คือมีแต่ข่าวหรือหน้าข่าวของหน่วยงานอื่น · หมายเหตุของผู้ตรวจอยู่ท้าย `notes` หลังคำว่า "ผู้ตรวจ:"
