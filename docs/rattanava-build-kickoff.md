# รัฐนาวา — บรีฟเริ่มสร้างตัวเกม (หลักไมล์แรก) สำหรับเซสชันใหม่

บันทึก 22 พ.ย. 2569 · อ่านคู่กับ `claude/rattanava-v2-design-brief.md` (แบบเกม) · `claude/rattanava-decisions.md` (ตัวเลขและคำตัดสิน) · `claude/rattanava-ui-rebuild-brief.md` (หน้าตา) · `claude/rattanava-project-memory.md` (ความต้องการตั้งต้น) · เมื่อขัดกันเรื่องลำดับงาน ให้ถือเอกสารนี้

## 1. คำสั่งของ Royin (22 พ.ย. 2569)

- หลังดูจอ PC ที่สร้างใหม่ (https://claude.ai/artifact/JkijqK1VtVJsXP8kLm4ALs#artboard-rebuild-desk-pc) เขาตอบว่า "ดูดีขึ้นครับ เริ่มสร้างตัวเกมได้เลยครับ" ถามว่าต้องทำใน Claude Code หรือไม่ และขอคำสั่งสำหรับเซสชันใหม่
- สิ่งที่ถือตามคำพูดนี้: หน้าตาของจอ PC ใหม่คือทิศทางที่ใช้ต่อ
- สิ่งที่เขายังไม่ได้พูด: ชอบส่วนใดของฉบับแรกที่สุด · อนุมัติรายการที่ Claude เลือกเองในจอนั้นทีละข้อหรือไม่ (รายการอยู่ใน ui-rebuild-brief หัวข้อสถานะ) · จะข้ามระยะ 0.5 (ต้นแบบใช้แล้วทิ้ง) หรือไม่
- ข้อเสนอของ Claude (ยังไม่ได้อนุมัติ): ไม่ทำต้นแบบแยกในแชท แต่ให้หลักไมล์แรกใน repo ทำหน้าที่ทดสอบว่าแกนเกมสนุกหรือไม่ และตัดสินไปต่อหรือหยุดที่ปลายหลักไมล์นี้

## 3. ขอบเขตหลักไมล์แรก

- ที่นั่ง กบน. ที่นั่งเดียว ฉากกองทุนน้ำมัน 8–12 ตา ตาละหนึ่งสัปดาห์ เล่นจบใน 15–25 นาที
- เว็บ static ไม่มีเซิร์ฟเวอร์ เล่นได้ทั้งมือถือและ PC หน้าจอภาษาไทย ปิด AI เซฟในเครื่อง
- วงรอบหนึ่งตา: ปฏิทินแจ้งเส้นตาย → แฟ้ม 2–4 ฉบับ → ทายผล → ตัดสินใจด้วยทุน 4 อย่าง → เห็นผล → ตามเงินได้ทุกตัวเลข
- ไม่ทำในหลักไมล์นี้: ที่นั่งอื่น · I-O 48 บล็อก · ผลรายจังหวัดบนแผนที่ · AI · โหมดกลุ่ม · แอตลาส

## 4. ลำดับงานและจุดหยุดรอ Royin

1. ถาม Royin 3 ข้อในหัวข้อ 6 ทีเดียวจบ
2. ตั้ง repo: `docs/` (เสร็จแล้ว) · `CLAUDE.md` · `PRODUCT.md` และ `DESIGN.md` (ถอดสี ฟอนต์ ส่วนประกอบจาก `project/rebuild-desk-pc.dc.html` ของผืน JkijqK1…) · ชุดเทคโนโลยีในแบบ v2 หัวข้อ 6 เป็นความเห็นที่ยังไม่ได้ตรวจ ให้ตรวจกับเอกสารปัจจุบันก่อน แล้วบอกตัวเลือกที่ใช้ในบรรทัดเดียว
3. ตรวจข้อเท็จจริงของฉากกับแหล่งต้นทางและหาข้อมูลที่ขาด (หัวข้อ 5) เก็บในไฟล์ข้อมูลกลางที่ทุกค่ามี ค่า หน่วย วันที่ แหล่ง URL และสถานะการตรวจ
4. เสนอกติกาของฉากแบบหยาบ 3–4 แบบ (หนึ่งตาทำอะไรได้ ทุนทำงานอย่างไร การทายผลให้คะแนนอย่างไร จบฉากอย่างไร) → **จุดหยุด: Royin เลือก**
5. เครื่องยนต์: deterministic ใช้ seed ไม่มี UI · บัญชีกองทุนลงสองด้าน ยอดรวมเป็นศูนย์ทุกงวด มีเทสต์บังคับ · golden run อย่างน้อยหนึ่งชุด
6. หน้าจอ: โต๊ะตามแบบ PC ที่มี · จอที่ยังไม่มีแบบในหน้าตาใหม่คือ ทายผล ผลสัปดาห์ ที่มาของตัวเลข มุมมองเงิน แผนที่ ปฏิทิน และรุ่นมือถือทั้งหมด · เสนอร่างหยาบของจอทายผลและจอผลสัปดาห์ก่อนทำละเอียด → **จุดหยุด: Royin เลือก**
7. Royin เล่นทดสอบ → **จุดหยุด: ตัดสินตามเกณฑ์ที่ตกลงในข้อ 1** ถ้าไม่ผ่าน หยุดขยายแล้วแก้แกนเกม (v2 หัวข้อ 9)

## 5. ข้อมูลที่ยังขาด (ไม่มีในเอกสารใดของโปรเจค)

- ปริมาณการใช้น้ำมันรายชนิดต่อวัน: ขาดตัวนี้จะคำนวณเงินเข้า–ออกกองทุนจากอัตราต่อลิตรไม่ได้ และเทียบกับรายจ่าย 32.46 ล้านบาทต่อวันไม่ได้
- โครงสร้างราคารายชนิด (ภาษี เงินกองทุน ค่าการตลาด) · อัตราของ LPG · ยอดแยกบัญชีน้ำมัน/LPG ณ วันอ้างอิงเดียว
- ตัวบท พ.ร.บ.กองทุนน้ำมันเชื้อเพลิง พ.ศ. 2562: อำนาจ กบน. กรอบวงเงิน เพดานการกู้ เลขมาตรา
- ตัวเลขใน decisions หัวข้อ 3 ทั้งหมดยังมาจากข่าว ยังไม่ได้เทียบประกาศ กบน. และเว็บไซต์ สกนช.
- `rattanava-research.zip` (ข้อมูล 77 จังหวัด ค่าฐานมหภาค บทที่ตรวจแล้ว) อยู่ในแชทเก่า เซสชันใหม่ไม่มีไฟล์นี้จนกว่า Royin จะแนบ · รูปจังหวัดในไฟล์ออกแบบไม่มีชื่อจังหวัดกำกับ

## 6. คำถามที่ต้องถาม Royin ก่อนเริ่ม

**ตอบแล้ว 22 พ.ย. 2569** — คำตอบอยู่ใน `rattanava-decisions.md` หัวข้อ 1

1. **ฉากเริ่มที่เดือนใด** — พ.ย. 2569: ตรงกับจอที่ออกแบบแล้ว แต่ตั้งแต่ตาที่ 2 ไม่มีข้อมูลจริงให้เทียบ · มี.ค. 2569 (จุดสูงสุดของวิกฤต): มีลำดับเหตุการณ์จริงถึง พ.ย. ให้เทียบผล แต่ต้องเปลี่ยนตัวเลขและเอกสารบนจอ (decisions หัวข้อ 3)
2. **วัดความสนุกอย่างไร** — ค่าที่ใช้อยู่คือเล่นคนเดียว แต่เกณฑ์ผ่านข้อ 2 ของ v2 ต้องมีผู้ทดสอบ 5 คน
3. **เวลาที่มีต่อสัปดาห์** — แผนใน v2 ตั้งบน 8–15 ชั่วโมง ซึ่ง Royin ยังไม่ได้ยืนยัน
