## ยังไม่ได้ตรวจ

- ยังไม่ได้รันบนเบราว์เซอร์หรือเครื่องจริง: การลบข้อมูลหลัง 7 วันบน iPhone · ผลของ `persist()` · การติดตั้งลงหน้าจอหลัก · module worker · การแสดงฟอนต์ไทย · golden run บน Safari ให้ผลตรงกับ Node หรือไม่
- เว็บไอคอนบนหน้าจอหลักของ iOS ได้รับยกเว้นจากการลบ 7 วันหรือไม่ แหล่งยังขัดกัน · บั๊ก WebKit 271401 (persist() คืน false) แก้แล้วหรือไม่ · สองข้อนี้เห็นจากผลค้นหาเท่านั้น ยังไม่ได้เปิดหน้าจริง
- ถ้า persist() ได้รับอนุญาต จะยกเว้นการลบ 7 วันหรือไม่: ไม่มีแหล่งต้นทางปัจจุบันบอก (MDN ไม่ได้พูดถึง)
- เกณฑ์การติดตั้งบน Android Chrome · ข้อที่ว่า GitHub Pages ตั้ง header เองไม่ได้ มาจากความจำ ยังไม่ได้ตรวจ · วันออกของ GitHub Actions ใช้วันของ commit ที่ติด tag เพราะเปิด releases API ไม่ได้
- ขนาดของ Svelte และ Solid เป็นค่าประมาณ (ไม่ได้ build ผ่าน plugin ของตัวเอง) · วันที่ Solid 2 ออกมาจาก npm และข้อความย่อในผลค้นหา · ยังไม่ได้อ่านหน้า "differences to React" ของ Preact
- ยังไม่ได้เปิดบล็อกประกาศ TS 7.0 คำแนะนำให้ใช้ @typescript/typescript6 คู่กันมาจากข้อความย่อในผลค้นหา
- ผลของ sfc32 ยังไม่ได้เทียบกับ test vector ของตัวอ้างอิงภาษา C
- สิทธิ์ในข้อมูลเส้นขอบต้นทางของกรมการปกครอง
- รุ่นที่เลือกหลายตัวออกมาไม่ถึงสองสัปดาห์ (fast-check 4.11.0, Vitest 5.1.1, Vite 8.3.8) ทำงานร่วมกันได้ในการลอง แต่ถ้าต้องการรุ่นที่ออกมาแล้วอย่างน้อยสองสัปดาห์ ให้ล็อกรุ่น patch ที่เก่ากว่า
