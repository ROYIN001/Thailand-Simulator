# รัฐนาวา — บันทึกโครงการ: ความต้องการ ไอเดีย การตัดสินใจ และสถานะ

อัปเดตล่าสุด 19 พ.ย. 2569 · ชื่อเกมชั่วคราว "รัฐนาวา" · สถานะ: ออกแบบรอบสองเสร็จ (v2 «หนึ่งประเทศ หลายที่นั่ง») Royin ให้เริ่มสร้าง ขั้นถัดไปคือระยะ 0.5 (ต้นแบบ) ยังไม่มีโค้ด

## 0. อ่านก่อน (19 พ.ย. 2569)

- **แบบปัจจุบันอยู่ใน `claude/rattanava-v2-design-brief.md`** เมื่อขัดกับหัวข้อ 3, 5, 7 หรือ 9 ของเอกสารนี้ ให้ถือเอกสารนั้น
- หัวข้อ 1 (สิ่งที่ Royin ต้องการ) ยังเป็นแกนที่เปลี่ยนไม่ได้ · หัวข้อ 2–7 คือประวัติของแบบรอบ 1 เก็บไว้อ้างอิง
- ลำดับเหตุการณ์: 17–18 พ.ย. แบบรอบ 1 เสร็จ → 18 พ.ย. Royin ขอให้ค้นคว้าละเอียดแล้วออกแบบใหม่ → 18 พ.ย. รายงานวิจัยและแบบ v2 → 19 พ.ย. Royin ให้เริ่มสร้าง

## 1. สิ่งที่ Royin ต้องการ (จากที่เขาพูดเอง)

- โปรแกรมหรือเกมที่เล่นได้ จำลองการทำงานของประเทศไทยทั้งประเทศให้ละเอียดที่สุด ครอบคลุมภาครัฐทุกหน่วยงานและกระทรวง รวมถึงภาคเอกชนส่วนต่างๆ
- เป้าหมาย: เล่นแล้วเข้าใจระบบการทำงานของแต่ละภาคส่วนอย่างจริงจัง และสนุกไปในตัว
- ให้ผสมจุดเด่นของทั้ง 4 แนวทางที่เสนอเป็นชุดเดียว และออกแบบให้เห็นหน้าตาก่อน
- ค่อยๆ ทำ ไม่ต้องรีบ เน้นรายละเอียดครบถ้วนและถูกต้อง ใช้เครื่องมือได้ทุกอย่าง ถามได้ถ้าสงสัย
- กระจายงานให้หลาย agent ทำพร้อมกันได้ ไม่ติดลิมิต 5 ชั่วโมง
- 18 พ.ย. 2569: ให้ค้นคว้าจากทุกแหล่งอย่างละเอียดแล้วออกแบบใหม่อีกครั้ง เก็บส่วนดีของแบบเดิมได้ หรือเสนอไอเดียที่ดีกว่ามากได้เลย

## 2. แนวทางตั้งต้น 4 แบบ (ถูกผสมรวมกัน)

| แบบ | แก่น | สิ่งที่นำมาใช้ |
|---|---|---|
| A ห้อง ครม. | ผู้เล่นเป็นนายกฯ ตัดสินใจรายเดือน | วงรอบการเล่นหลัก |
| B แฝดดิจิทัล | แบบจำลองเศรษฐกิจละเอียด | เครื่องยนต์คำนวณ |
| C แผนที่ 77 จังหวัด | ผลเชิงพื้นที่ | ชั้นแผนที่และภัยตามพื้นที่ |
| D หลายบทบาท + AI | หน่วยงานเป็นตัวละคร | ชั้นสถาบันและตัวละคร AI |

## 3. แบบที่รวมแล้ว (สรุป) — แบบรอบ 1 ถูกแทนที่ด้วย v2

**4 ชั้น**
1. **ชั้นเล่น:** หนึ่งตา = หนึ่งเดือน 6 ขั้น (รับรายงาน → ตัดสินใจ วาระหลักไม่เกิน 3 เรื่อง → ทายผล → ประชุม ครม./สภา → ราชการขับเคลื่อน → จำลองและสรุป) ตาละ 6–10 นาที
2. **ชั้นสถาบัน:** หน่วยงานจริงเป็นตัวละคร มีงบ บุคลากร ขีดความสามารถ 0–100 อำนาจตามกฎหมาย KPI หัวหน้าหน่วยงาน · สายพานนโยบาย ข้อเสนอ → มติ ครม. → กฎหมาย/ระเบียบ → งบประมาณ → จัดซื้อจัดจ้าง → ลงมือ → เห็นผล · พรรคร่วมสมมติต่อรองด้วยคำมั่น
3. **เครื่องยนต์รายเดือน:** stock–flow + ตาราง I-O 16 สาขา + เวลาหน่วงแบบ System Dynamics, ครัวเรือน 5 กลุ่ม, 6 ภูมิภาค → 77 จังหวัด, CPI = 0.6968 พื้นฐาน + 0.1743 อาหารสด + 0.1289 พลังงาน, กนง. เป็นตัวละคร AI ใช้กฎแบบ Taylor เฉพาะเดือนที่มีประชุม (6 ครั้ง/ปี), หนี้ต่อ GDP คิดแบบ สบน., พารามิเตอร์ติดป้าย งานวิจัย/คำนวณ/ค่าของเกม, ทดสอบย้อนหลัง 2540–41, 2551–52, 2554, 2563, 2568, 2569
4. **ชั้นพื้นที่:** แผนที่ 77 จังหวัด ชั้นข้อมูลเศรษฐกิจ ประชากร สวัสดิการ สิ่งแวดล้อม การเมือง โครงการ

**ระบบการเรียนรู้:** ปุ่ม "ทำไม?" สองชั้น (กราฟน้ำตกสาเหตุ ≤5 รายการ → เส้นทาง เวลาหน่วง ป้ายหลักฐาน) · ทายก่อนเห็นผล เฉลยสองจังหวะ · สายพานนโยบาย · คลังความรู้พร้อมแหล่ง · สรุปเดือน + คำถามสะท้อนคิด · ค่าคาดการณ์แสดงเป็นช่วง · เปิดระบบทีละชั้น (เดือนแรก 6 ตัวชี้วัด + 5 กระทรวง, ช่วง "100 วันแรก")

**ตัวชี้วัดหลัก 6 ตัว:** GDP เงินเฟ้อ ว่างงาน หนี้สาธารณะ หนี้ครัวเรือน คะแนนนิยม (+ ตัวชี้วัดตามพันธกิจไม่เกิน 2)

**คะแนน:** พันธกิจ 3 ข้อที่ผู้เล่นเลือก · บัตรรายงาน 3 แกน (ผลตามพันธกิจเทียบเส้นฐาน "ถ้าไม่ออกนโยบายใหม่" / การเมือง / ความเข้าใจ) ไม่รวมเป็นคะแนนเดียว

**ความยาก:** แยก "ความช่วยเหลือ" กับ "ความท้าทาย" 4 ระดับ (ฝึกหัด มาตรฐาน สมจริง วิกฤต) สมการชุดเดียว

**โหมด:** วาระ 4 ปี (48 ตา) · ฉากบทเรียน (น้ำท่วม 2554 โควิด 2563 ภาษีสหรัฐฯ 2568 ฯลฯ) · แผน 20 ปี · กระบะทราย · บทสอนเล่น · บทบาท 8 แบบ (นายกฯ รมว.คลัง กนง. รมว.กลาโหม ผู้ว่าฯ ฯลฯ)

**กติกา AI:** เครื่องยนต์ตัดสิน AI เล่าเรื่อง · ใบข้อเท็จจริง → AI ตอบ JSON → ตัวตรวจตัวเลขและหัวข้อต้องห้าม → ไม่ผ่านใช้ข้อความแม่แบบ · ข้อความที่ผู้เล่นพิมพ์เปลี่ยนสถานะเกมไม่ได้ · เล่นได้ครบเมื่อปิด AI · ต้นทุนประมาณ 0.01–0.19 USD ต่อตา (ราคา พ.ย. 2569)

**ความเป็นกลาง:** หน่วยงานจริง พรรคการเมืองและนักการเมืองสมมติ · สถาบันพระมหากษัตริย์ปรากฏเฉพาะเป็นขั้นตอนตามรัฐธรรมนูญ · ไม่มีกลไกรัฐประหาร · ความมั่นคงเล่นระดับนโยบาย · นโยบายที่ถกเถียงแสดงหลักฐานทั้งสองฝั่ง · บริษัทจริงใช้แค่เป็นโครงสร้างตลาด

## 4. การตัดสินใจที่ Claude เลือกแทน (Royin เปลี่ยนได้)

- เว็บ เล่นได้ทั้งมือถือและ PC · โค้ดสร้างด้วย Claude Code หลังแบบผ่านอนุมัติ · หน้าจอภาษาไทย
- ฉากเริ่ม พ.ย. 2569 ด้วยข้อมูลจริงล่าสุด ตรึงเป็นฉากมาตรฐาน + มีฉากล่าสุดที่อัปเดตรายไตรมาส
- บทหลักคือนายกฯ · กนง. อยู่นอกอำนาจรัฐบาล (v2: นายกฯ เป็นที่นั่งที่ปลดล็อกภายหลัง)
- คะแนนนิยมเริ่ม 50% เป็นค่าตั้งต้นของเกม ไม่ใช่ผลสำรวจ
- AI ไม่ตัดสินผลที่เปลี่ยนสถานะเกม · มติสถาบันคำนวณจากสถานะแบบไม่สุ่ม · ความสุ่มใช้เฉพาะช็อกภายนอกและความเสี่ยงระหว่างลงมือ มี seed เล่นซ้ำได้
- ทดสอบย้อนหลังเริ่มจากค่าระดับรวมของปีจริงและป้อนเส้นทางตัวแปรภายนอกจริง · ฉากบทเรียนใช้ประเทศปี 2569 แล้วใส่ช็อกแบบเหตุการณ์จริง · ฉาก 2540 ต้องมีโมดูลค่าเงินคงที่เพิ่ม
- ข้อมูลรายเดือน/ไตรมาสอัปเดตทุกไตรมาส ข้อมูลรายปีปีละครั้ง

## 5. แผนการสร้าง 7 ระยะ — แบบรอบ 1 ถูกแทนที่ด้วยแผนใน v2

0 ออกแบบ (เสร็จ รออนุมัติ) → 1 แกนที่เล่นได้ (20 กระทรวงแบบย่อ งบประจำปี วิกฤตตามฤดู "ทำไม?" มือถือ+PC; เกณฑ์: เล่น 12 เดือนจบไม่สะดุด) → 2 เครื่องยนต์เต็ม (16 สาขา 6 ภาค ทดสอบย้อนหลัง) → 3 ชั้นสถาบันเต็ม → 4 แผนที่และท้องถิ่น → 5 บทบาทและฉาก → 6 ขัดเกลา · ระยะ 1 สำคัญที่สุด เพราะเป็นครั้งแรกที่รู้ว่าแกนเกมสนุกจริงไหม

## 7. คำถามที่ค้าง (ของแบบรอบ 1 — ค่าที่ใช้อยู่ตอนนี้ดู v2 หัวข้อ 2)

1. ใครจะเล่น (เล่นเอง / เพื่อนร่วมรุ่น / สาธารณะ) และใช้ AI ตั้งแต่ระยะ 1 หรือไม่ ใครจ่าย เพดานต่อเดือนเท่าไร — ชี้ว่าต้องมีเซิร์ฟเวอร์หรือไม่ ถ้าเปิดสาธารณะควรดูข้อกำหนดต้นสังกัดเรื่องเนื้อหาการเมือง
2. เลือกทิศทางภาพ A/B/C/D หรือผสม — กระทบลำดับการสร้าง (D ต้องมีผลรายจังหวัดตั้งแต่ระยะ 1)
3. เป้าหมายและเวลา: ทำระยะ 1 ก่อน หรือวางแผนครบ 6 ระยะ มีวันที่ต้องเสร็จไหม

Royin ยังไม่ได้ตอบสามข้อนี้โดยตรง · v2 ใช้ค่าเริ่มต้น: เล่นคนเดียว ปิด AI ไม่มีเซิร์ฟเวอร์ · ภาพ B+C · วางแผนถึงชิ้นแรก ไม่ผูกวันที่

## 8. ข้อจำกัดที่ต้องจำตอนสร้าง

- บทเกมอ้างอิง (กลุ่ม 14) ยังไม่ผ่านผู้ตรวจอิสระ
- GPP รายจังหวัดในไฟล์ข้อมูลยังเป็นปี 2566 (เบื้องต้น) · มีชุดปี 2567 แล้ว ต้องอัปเดต · GDP Q3/2569 ออกแล้ว (+2.9%) ต้องอัปเดต
- ตาราง I-O ล่าสุดของ สศช. คือปี 2564 (2021) 180 สาขา ไม่ใช่ปี 2558 ตามที่เคยเชื่อ · วันเผยแพร่ยังไม่ได้ยืนยัน
- ถ้า research/ ขัดกับ chapters/ หรือ data/ ให้ถือ chapters/ และ data/ เป็นหลัก
- เส้นขอบจังหวัด OpenGISData-Thailand (CC BY 4.0 ประกาศใน README) ต้องใส่เครดิต
- ขั้นสร้างโค้ดจริง (ระยะ 1 เป็นต้นไป) ควรทำใน Claude Code กับ git repo โดยใช้ไฟล์ zip และเอกสาร v2 · ระยะ 0.5 ทำในแชทใหม่ของโปรเจคนี้
- รายงานรอบสองระบุเองว่าค้นได้ไม่ครบ รายการที่ยังไม่ได้ตรวจอยู่ใน v2 หัวข้อ 11

## 9. ขั้นต่อไป

ระยะ 0.5 ในแชทใหม่ของโปรเจคนี้ ตามขั้นใน v2 หัวข้อ 10: ตกลงวิธีวัดความสนุกและเวลาที่มีต่อสัปดาห์ → ตรวจข้อเท็จจริงของฉากกองทุนน้ำมัน → เสนอกติกาแบบหยาบ 3–4 แบบให้ Royin เลือก → ทำต้นแบบใช้แล้วทิ้ง → เล่นทดสอบและตัดสินตามเกณฑ์ → ผ่านแล้วจึงเริ่มระยะ 1 ใน Claude Code
